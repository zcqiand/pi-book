# Pi 从入门到项目实践 - 代码清单

## 关于本书

《Pi 从入门到项目实践》是一本锚定 Pi 1.0.2 冻结版本写作、面向工程化实战的终端 AI 编程智能体教程书：以 MIT 开源、模型无关的 Pi（pi CLI）为载体，沿「用工具 → 改工具 → 嵌工具」的完整阶梯，从安装跑通走到 TypeScript 扩展开发与 packages 分发，再到 CLI／JSON 事件流／RPC／SDK 嵌入自有系统与 CI，最终在两个冻结 tag 的真实 Next.js 15 全栈仓上完成项目实践收官。正文只讲稳定概念（智能体循环、会话树、扩展模型、SDK 契约），易变的安装命令与界面细节集中在附录并标注「截至 Pi 冻结版本」。

全书 36 章六卷：卷一入门篇·第一次驱动终端智能体（心智模型与模型选型），卷二日常篇·把 Pi 用成主力工具（交互、提示词、会话三技能与两轮实战），卷三定制篇·从用到改（自研扩展包并分发共享），卷四自动化篇·从命令行到嵌入式（脚本化与嵌入式两条程序化通道、无人值守安全边界），卷五项目实践一·saas 身份平台全栈切片（契约先行六层切片：契约→数据→服务端→前端→测试→部署），卷六项目实践二·实验室管理系统攻坚（功能切片、跨仓协同、缺陷攻坚、性能观测，以双仓复盘与工作流收束）。实战章 17 章占全书 47%。你不一定用过 Pi：有任意一门编程语言基础、会用命令行即可开读；已在用其他 AI 编程工具的开发者，可从第 1 章的三类工具选型对照切入。

## 本书特点

**第一，开源模型无关主线，不被厂商绑架。** Pi 为 MIT 协议，可源码级讲解；订阅、API key、本地模型均可接入，15+ 模型提供商自由切换，书稿不被单一厂商的产品迭代节奏牵着走。

**第二，「用→改→嵌」完整阶梯一次走通。** 从日常使用到 TypeScript 扩展开发与 packages 分发，再到 CLI、JSON 事件流、RPC、SDK 四通道嵌入生产与 CI 流水线，不满足于「会用」。

**第三，双真实案例仓贯穿，终点不是示范小工具。** 后半部 17 章在两个冻结 tag 的 Next.js 15 全栈仓上做契约先行切片、部署上线与跨仓攻坚，每章交付物落到可验证端口与构建测试，clone 即跑。

**第四，安全当纪律讲，双防线独立成章。** Pi 以宿主权限运行、不提供沙箱——第 10 章立交互期信任机制与危险命令拦截，第 19 章立无人值守最小权限边界，从第一天起训练三条纪律：信任确认、危险命令拦截、最小权限自动化。

**第五，通识兜底，换工具也不白学。** 开篇即给终端智能体选型对照（智能体、补全工具、聊天助手三类边界），即使你最终选的不是 Pi，也能带走一套完整的终端 AI 工程化方法论。

**第六，每章交付物导向，版本冻结口径可追溯。** 学完的标准不是「读完」，而是章末交付物逐项达成；全书锚定 Pi 1.0.2 冻结版本与双仓冻结 tag，每章代码与命令标注来源仓与版本口径，可运行、可测试、可追溯。

### 运行环境

```bash
# Pi 本体安装（Node.js >= 22.19；全书实测锚定 Pi 1.0.2，第 2 章含平台适配专节）
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
pi --version
# 模型接入三选一：订阅 / API key / 本地模型（15+ 提供商接入与选型见第 4 章）
# 案例卷（第 20-36 章）环境要求：Node.js、Git、PostgreSQL
node --version
git --version
psql --version
# 克隆双案例仓库后切到冻结 tag（仓库地址随本书配书资源公布）
cd saas-identity-platform-nextjs
git checkout v0.7.70-20261004
npm ci
npm run dev
# 浏览器访问 http://localhost:5101（lab-management-system-nextjs 为 5201）
```
